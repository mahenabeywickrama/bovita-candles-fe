# 🕯️ Bovita Candles – Frontend

A modern, responsive e-commerce frontend for **Bovita Candles**, designed to showcase handcrafted luxury candles with an elegant user experience. The application focuses on brand storytelling, product discovery, and smooth navigation for all visitors.

---

## 🌟 Features

- Elegant **Hero Section** highlighting brand identity
- Product showcase with best sellers
- Category-based browsing (Shop by Mood)
- Customer testimonials (social proof)
- Call-to-action sections for conversions
- Fully responsive design (mobile, tablet, desktop)
- Clean UI built with reusable components

---

## 🛠️ Technologies Used

- **React** (with TypeScript)
- **React Router DOM**
- **Tailwind CSS**
- **Vite** (development & build tool)
- **Context API** (authentication state)
- **ESLint & Prettier** (code quality)

## 🚀 Setup & Run Instructions

### 1️⃣ Clone the repository
```bash
git clone https://github.com/your-username/bovita-candles-frontend.git
cd bovita-candles-frontend
```

### 2️⃣ Install dependencies
```bash
npm install
```

### 3️⃣ Run the development server
```bash
npm run dev
```

The frontend will be available at: `http://localhost:5173`

## 📁 Project Structure
```
src/
 ├── components/    # Reusable UI components
 ├── pages/         # Page-level components
 ├── context/       # Context API for state management
 ├── services/      # API services and utilities
 ├── layouts/       # Layout wrappers
 ├── routes/        # Routing configuration
 └── main.tsx       # Application entry point
```

---

## 📌 Notes

- This frontend consumes REST APIs provided by the Bovita backend
- Authentication-based UI rendering is handled via Context API
- Designed with scalability and maintainability in mind
